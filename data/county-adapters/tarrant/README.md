# Tarrant County TAD Pilot Adapter

This is a pilot county adapter for Tarrant County / TAD.

## Status

`pilot`

The folder is intentionally not active in the app yet. It defines the target contract for source files, join keys, owner enrichment, public data roots, QC, and pipeline steps. Source files and exact field mappings still need to be verified before this county can become active.

## Next Inputs Needed

- Tarrant parcel geometry source
- Tarrant appraisal/account extract
- Exact parcel geometry to appraisal account join key
- Owner-name and mailing-address field mappings
- Official permit/development sources
- Verified row/feature counts

## UI Rule

This adapter is data plumbing only. Do not redesign or restyle any White Rabbit pages while working on this pilot.
